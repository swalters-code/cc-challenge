# cc-challenge
A collection of personal programs written for my Computercraft Challenge worlds.


## Installation

In your computercraft world, run the following command to download the installer script:

```
wget https://raw.githubusercontent.com/swalters-code/cc-challenge/main/install.lua install.lua
```

From there, run the installer script with the name of the role you are installing.

The current world will be selected server-side, but you can change it in the installer script if needed.

There is also a world-specific version of the installer script in each world folder that can be used to install roles from that world only.
